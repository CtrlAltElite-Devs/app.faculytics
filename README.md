# Faculytics v2

Faculytics v2 is a Next.js frontend for a multi-role faculty evaluation workflow. Students submit course feedback, faculty review outcomes, and administrators manage broader questionnaire and analytics experiences.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Query
- Axios
- Zustand

## Getting Started

```bash
npm run dev
```

Open `http://localhost:3000`.

## Quality Checks

```bash
bun run lint
bun run typecheck
```
